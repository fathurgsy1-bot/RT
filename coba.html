Cara Menggunakan di Canva:

  1. Klik tombol "Unduh Format SVG" pada masing-masing aset di atas. File akan tersimpan di komputer Anda.
  2. Buka situs web atau aplikasi Canva dan buat desain baru (Pilih "T-Shirt" atau custom size 4500x5400 px).
  3. Di menu sebelah kiri Canva, pilih Unggahan (Uploads), lalu klik "Unggah File" dan pilih file SVG yang baru saja diunduh.
  4. Tarik file SVG tersebut ke kanvas desain Anda.
  5. Fitur Spesial: Karena ini file SVG (vektor), Anda bisa mengklik gambar tersebut di Canva dan mengubah warna setiap elemennya melalui palet warna di bagian atas layar Canva!
  6. Tambahkan teks kustom tambahan di Canva jika diperlukan menggunakan font Urbanist atau Azeret Mono.
